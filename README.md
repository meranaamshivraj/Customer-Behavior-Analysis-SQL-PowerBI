# Customer Behavior Analysis Using SQL and Power BI

## Project Overview

This project focuses on analyzing customer behavior using SQL and Microsoft Power BI. The workflow involves preparing and cleaning raw customer data using SQL and developing an interactive Power BI dashboard to explore customer-related patterns and insights.

## Tools and Technologies

* MySQL
* MySQL Workbench
* Microsoft Power BI
* SQL
* Data Cleaning
* Data Visualization

## Project Workflow

1. Obtained a raw customer behavior dataset from an online source.
2. Imported the dataset into MySQL.
3. Cleaned and prepared the data using SQL queries.
4. Imported the cleaned data into Microsoft Power BI.
5. Developed a dashboard to visualize customer behavior and relevant metrics.

## Data Cleaning

SQL was used to clean and prepare the raw dataset before visualization.

The specific cleaning operations are documented in the SQL scripts included in this repository.
